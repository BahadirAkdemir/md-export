# Changelog

## 0.0.1

Initial release.

- Export Markdown to PDF, HTML, DOCX, RTF, EPUB, XML (DocBook), and PNG
- GitHub-Flavored Markdown (tables, task lists, strikethrough, footnotes)
- Syntax highlighting via Shiki, KaTeX math, Mermaid diagrams
- YAML front-matter overrides, optional auto table of contents
- Four built-in themes (`github`, `academic`, `minimal`, `dark`) plus custom CSS
- Context-menu and status-bar export; no system pandoc or wkhtmltopdf required
